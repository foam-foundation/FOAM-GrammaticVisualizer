# Traps hit while spiking FOAM pages (all verified 2026-09)

| Trap | Symptom | Fix |
|---|---|---|
| missing `<meta charset="utf-8">` | glyphs (✓ ▶ ✗ ⊣) render as mojibake | add the meta tag first in `<head>` |
| `project=` on the `foam.js` tag replaces the default pom list | `foam.u2` or `foam.graphics` classes undefined, page blank | list `foam3/src/pom` first, then the skill's `references/fsm-pom` (loads `foam.FSM`), then any app poms you need |
| CView already owns a `color` property | `Illegal to change Property to non-Property` when the class loads | never define a `color()` method on a CView subclass; prefix domain methods (`outcomeColor()`) |
| variable-length children in a CView | an `expression:` cannot depend on an array of child slots | `foam.lang.ArraySlot.create({ slots: kids.map(k => k.height$) }).sub(this.layout)` and call `layout()` once |
| u2 `Element` has `call(fn)` (mixin `foam.lang.Fluent`, `foam3/src/foam/u2/Element2.js:439`); the TypeError comes from calling it on a plain DOM node or a slot | `TypeError: ….call is not a function` | `this.start('div', null, this.tipEl$)` captures the element into a slot; `forEach(array, fn)` renders lists |
| `new Function(names, body)` for a grammar `symbols` wrapper | `Grammar.SYMBOLS.adapt` mis-parses parameter names | build `return function(a, b, c) { … }` with the parameter list on ONE line |
| Chrome caches spike JS | edits invisible, old bugs "come back" | hard-reload (Cmd+Shift+R); from MCP `await fetch(url, {cache:'reload'})` then `location.reload()` |
| Chrome-MCP coordinate clicks after a window resize | clicks land on the wrong element | dispatch `PointerEvent`s from `javascript_tool` at page coordinates (see chrome-mcp-driving.md) |
| `find` refs after scrolling | stale refs, clicks miss | re-query, or use `element.click()` from JS |
| hidden or background tab | u2 slot text and `FSMDiagramView` never update (`SlotNode` subscribes to `slot.framed()`, and Chrome fires no `requestAnimationFrame` in a hidden tab); timers throttle, Play looks slow | keep the tab visible; from Chrome MCP, take a screenshot after each action (it briefly activates the tab and flushes the frame) before reading the DOM |
| status text with long tokens | horizontal scrollbar on the page | `white-space: pre-wrap; overflow-wrap: anywhere` on the status element, `min-width: 0` on its column |
| singleton parser objects (`foam.parse.EOF`) reused across a tree | one object, many places; display keyed by object shows the wrong one lit | key display state by structural path, never by object identity |
| `foam.lookup` of every `foam.UNUSED` model | seconds of stall and a console flood of unrelated class errors | peek the raw model (`foam.UNUSED[id].extends`, `.grammars`) and build only matches |
| `fit()` that fits ALL content | a tall page shrinks to slivers | fit width, scroll vertically, "fit all" as a secondary action |
| your gitignore hides `.claude/` | `git add` of a skill file fails with "ignored by one of your .gitignore files" | `git add -f` |
| `foam.FSM` `validateMachine()` | `TypeError: Cannot convert undefined or null to object` at `StateMachineEnum.js:421`, and if called from `init` the view never renders | known-broken in foam3 as of 2026-10-01 (`onTransition` property commented out); use the `checkMachine()` snippet from `statechart.md`; never call `validateMachine()` inside `init` |
| `FSMDiagramView` class id | `Requires: Unknown class: foam.lang.FSMDiagramView` | the file is `FSMDiagramView.js` in the FSM folder but the class is `foam.u2.view.FSMDiagramView`; require that id |
| `FSMDiagramView` drawn once | highlight stays on the initial state after transitions; a tuning form appears above the SVG | re-create the view from `this.state$.map(...)` (recipe in statechart.md); hide the form with `.foam-u2-DetailView { display: none }` |
| mermaid 11 composite states are `g.statediagram-cluster` with id `…-state-NAME-n`, not `g.cluster` `…-NAME` (mermaid 10) | a `g.cluster` selector finds nothing, so "click header to collapse" silently does nothing | `spike-diagram.js` matches both and binds the click to the header label only, so a member click is not also a collapse |
| rebuilding a form synchronously inside a `change` handler | Tab after editing a field lands nowhere: the rebuild destroyed the element the browser was about to focus, so focus falls to `<body>` | defer the rebuild one tick (`setTimeout(..., 0)`), then refocus by a stable attribute (`data-key`) and restore the caret with `setSelectionRange` |
| `foam.u2.table.TableView` in a bin built from `foam3/src/pom` alone | `Cannot read properties of undefined (reading 'ColumnConfigToPropertyConverter')`, table never renders | its column helpers live in `foam3/src/foam/core/pom`; add that pom, or use the older `foam.u2.TableView`, which needs only the root pom |
| `foam.FSM` guard written as "return true when allowed" | the move is refused exactly when it should be allowed (`transitionXTo` throws `Error(true)`), and allowed when it should be refused | a guard returns the REFUSAL reason: `''` allows, a non-empty string blocks (`StateMachineEnum.js:197-201` in the FSM folder); reuse that string as the disabled button's reason |
| legacy `foam.u2.TableView` | header labels bunch up on the left, cells don't sit under them | the view wraps its header `<tr>` in a `<div>` inside `<table>` (invalid HTML; the browser hoists it out of the grid). Measured 2026-09-25. For a small table on a spike page, build `start('table')` rows by hand |
| `foam.u2.table.TableView` on a spike page (with `foam/core/pom` added) | header renders, a broken image icon sits at its end, no rows appear | not worth debugging on a throwaway page; hand-build small tables. Cause unverified (the view is built for app DAOs and its column menu assets) |
| `foam.u2.Tabs` | URL gains `#selectedLabel=…` on every tab click | memento, harmless; the page reopens on the last tab |
| page CSS hardcoded light while the OS is in dark mode | FOAM selects, buttons and radios turn dark on a light page (the default theme has `useVariants` on and follows `prefers-color-scheme`, `foam3/src/foam/lang/Window.js:164-189`) | use the `--sp-*` colour tokens from `spike-shell.js` (light and dark values) for every colour, the design's included; mermaid theme `dark` when the OS is dark; `classDef` fills that stay light need an explicit dark text `color:` |
| a constant named like a property in upper case (`constants: { FRAME }` beside property `frame`) | blank page; console: `Class constant conflict: …FRAME from: frame and undefined` | FOAM already makes `FRAME` for property `frame` (the property's axiom constant); name the constant something else (`FRAME_LINES`) |
| `foam.u2.view.ReadOnlyEnumView` on a spike page | throws on `this.returnExpandedCSS` while painting the badge | write a small badge view that reads the enum value's own `label` and colour axioms; cause unverified (`foam.lang.Window` does export `returnExpandedCSS`, `foam3/src/foam/lang/Window.js:71`). `foam.u2.DAOList` also misfits: it imports `config`, which a spike page has no provider for |
| `bar.add(this.MY_ACTION)` on a plain view | clicking the button throws `this.<method> is not a function`: the Action runs against the context's `data`, not the view | `bar.tag(this.MY_ACTION, { data: this })` |
| a scrolling list inside a flex column (kanban column, side panel) | cards are squashed: text cut mid-line, some lines vanish instead of the list scrolling | `flex: 1 1 auto; min-height: 0; overflow-y: auto` on the list, `flex-shrink: 0` on each card |
| `transition: opacity` on an element FOAM re-renders | hover/focus rules that should change the opacity never apply, even with `!important` (the transition keeps restarting, and a running CSS transition outranks `!important`) | no transition on that property; flip it instantly |
| a page that saves its UI state in `localStorage` | after testing, the page opens with a leftover filter and looks broken | clear the saved state after testing, and wrap every `localStorage` read/write in `try/catch` |
